NEXA — PREMIUM AI AUTOMATION AGENCY
=====================================

This is a modern, fast-loading frontend built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Motion (Framer Motion ecosystem) loaded as an ES module for reveal animations
- CSS 3D / perspective interactions
- Premium responsive UI

SECTIONS:
- Premium animated hero
- 3D AI automation visualization
- Services
- Process
- Results / metrics
- Testimonials
- FAQ accordion
- High-converting CTA
- Responsive mobile navigation
- Magnetic buttons
- 3D card tilt
- Scroll reveal animations
- No heavy image library required

RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Use Live Server, or simply open index.html.
4. Internet is needed for Google Fonts and the Motion CDN.

NOTE:
"UI/UX Pro Max" is a design/Claude Code skill rather than a browser library, so its principles are represented in the visual system: strong hierarchy, restrained palette, spacing, conversion-focused CTAs, responsive layouts, accessible controls, and reusable components.
