# Qutab Chiragh Din Portfolio

A responsive personal portfolio made with plain HTML, CSS and JavaScript.

## Run
1. Open the folder in VS Code.
2. Open `index.html` in your browser, or use Live Server.
3. Replace placeholder email/social links and project links in `index.html`.

## Files
- index.html
- style.css
- script.js

The design is inspired by the structure and dark developer-portfolio feel of the reference site, while using original copy, layout details, and visuals.
